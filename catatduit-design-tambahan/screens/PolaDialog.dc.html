3. Toast (pengganti popup sukses)

HP: di atas bottom nav. Web: kanan bawah. Hilang sendiri 4 detik, error 6 detik.

Varian

Pengeluaran tersimpan
Transaksi dihapus
Data gagal disimpan.
Saldo Rp 210.000 dikembalikan ke BCA

Aturan

App lama memakai popup tengah untuk sukses (“Pengeluaran Dicatat!”). Ganti dengan toast supaya user tidak perlu menutup popup. Logika simpan tidak berubah.
Teks toast: objek + kata kerja lampau. “Dompet dihapus”, bukan “Dompet berhasil dihapus beserta…”. Tanpa emoji, tanpa tanda seru.
Tombol Urungkan = fitur baru opsional. Kalau belum dibuat, toast hapus tampil tanpa tombol.
Error yang menghalangi simpan (saldo kurang, data kosong) tampil di field, bukan di toast. Toast error hanya untuk gagal jaringan/server.
